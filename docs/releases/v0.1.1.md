## DroidStudioLite v0.1.1

- 新增“帮助 → 检测更新”，通过本项目 GitHub API 比较当前版本与最新正式发布版。
- 发现新版本时可前往对应发布页下载；不推送草稿或预发布版本。
- 补充无正式发布版、网络失败、超时和请求受限提示，并防止重复检测。
- 帮助菜单提供使用说明和当前版本信息；更新中英文使用说明。

入口：打开窗口中的帮助菜单，选择“帮助 → 检测更新”。

下载 `DroidStudioLite-0.1.1.exe`，Windows x64 免安装版。

更新时先从程序菜单退出旧版本，再替换程序文件。现有用户配置保留。
附件 `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

### English

- Added Help → Check for updates using this repository's latest stable GitHub release.
- New releases offer a link to their release page; drafts and prereleases are excluded.
- Handles missing releases, connection failures, timeouts, rate limits, and repeated clicks.
- Includes usage help, current version information, and updated documentation.

Exit the previous version before replacing files. Existing user settings are preserved.
