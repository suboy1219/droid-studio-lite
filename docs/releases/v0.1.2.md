## DroidStudioLite v0.1.2

- Logcat 新增「记录」按钮，将点击时当前筛选的全部日志复制到新的编辑器标签页。
- 每份记录独立保留，实时日志继续输出或清空日志不会改变已记录的内容；暂停时记录当前暂停画面中的日志。
- 日志记录支持编辑、搜索和替换；点击「搜索」或按 `Ctrl+F` 打开查找面板。
- 支持多份带时间戳的日志记录；按 `Ctrl+S` 选择位置保存为 txt，之后直接保存到所选文件。
- 修复编辑器内按 `Ctrl+S` 重复触发保存的问题。

下载 `DroidStudioLite-0.1.2.exe`，Windows x64 免安装版。

更新时先从程序菜单退出旧版本，再替换程序文件。现有用户配置保留。
附件 `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

### English

- Added Record to Logcat: copy all currently filtered logs into a new editor tab at the moment of clicking.
- Each snapshot stays independent of incoming logs and log clearing. Recording while paused captures the paused log view.
- Edit, search and replace recorded logs using the Search button or `Ctrl+F`.
- Keep multiple timestamped snapshots and save them as text files with `Ctrl+S`.
- Fixed duplicate saves triggered by `Ctrl+S` inside the editor.

Download `DroidStudioLite-0.1.2.exe` for the portable Windows x64 build.
Exit the previous version before replacing files. Existing user settings are preserved.
Use the attached `SHA256SUMS.txt` to verify the download.
